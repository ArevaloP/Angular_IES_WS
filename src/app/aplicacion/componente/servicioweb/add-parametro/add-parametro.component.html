El tipo ARRAY requiere un listado adicional de parámetros, puede elegir un listado existente o crear uno desde cero. Si decide agregar uno nuevo deberá digitar el Código y el Nombre del listado. Los ítems(sub-parámetros) de este listado los podrá gestionar mediante el botón     (Listar parámetros del servicio) después de registrar en esta funcionalidad.
